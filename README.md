## 🧐 O strani

**For Valor Official** je uradna spletna stran igre *For Valor*.

Uporabniki lahko brez prijave:
- prenesejo igro,
- berejo posodobitve,
- raziskujejo vsebine strani.

Če se prijavijo (prek GitHuba ali profila), lahko:
- dodajajo komentarje,
- urejajo in brišejo svoje komentarje,
- urejajo svoj profil,
- gledajo profile drugih uporabnikov.

Cilj projekta je ustvariti osrednjo spletno platformo za razvoj in skupnost okoli igre *For Valor*.

---

## 🏁 Kako začeti

### Predpogoji
Če želiš projekt poganjati lokalno, potrebuješ:

Node.js (LTS)

npm ali pnpm

Git


### Nameščanje

1. Kloniraj projekt:

```git clone``` [forvalorofficial](https://github.com/zuranmateo/forvalorofficial.git)



2. Namesti odvisnosti:

        npm install

    ali:

        pnpm install



3. Zaženi development server:

        npm run dev
    
    ali:

        pnpm dev

## 🎈 Uporaba

Uporabniki lahko:
- prenesejo igro,
- berejo posodobitve,
- ustvarijo profil ali se prijavijo z GitHubom,
- komentirajo objave,
- urejajo/brišejo svoje komentarje,
- urejajo svoj profil.

### Kako kaj?

#### Kako se prijaviti

prijaviš se lahko na strani ```/login```. Zgoraj desno v navigacijski vrstici se nahaja. Nato lahko greste na registracijo, ki je na dnu okna za prijavo, če se želite prijaviti z imenom in geslom. če se želite prijaviti z Github profilom, se s tem lahko prijavite na strani za prijavo.

#### Kako komentirati

komentira lahko vsaka prijavljena oseba. Na strani ```/comments``` je gumb ```comment+```, ki vodi na stran za pisanje komentarja.

#### Kako urejati profil in komentarje

oboje se ureja na strani za profil. Na navigacijski vrstici je gumb za profilno stran. Če ste na svoji profilni strani, si lahko urejate profil ali komentarje tako, da pritisnete na oznako za urejanje, ki je v zgornjem desnem kotu vseh komponent.
***V kolikor ste prijavljeni z Github profilom, urejanje profila ni mogoča***
